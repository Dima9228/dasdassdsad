# Волна

Свой аналог Discord: серверы, текстовые каналы, личные сообщения и общение в реальном времени.
Без внешних сервисов — один Node.js-процесс и файл с данными.

```
npm install
npm start
```

Откройте http://localhost:3000, создайте аккаунт — и вы уже в чате.

## Что умеет

- **Аккаунты** — регистрация и вход по имени и паролю (scrypt-хеши, токены сессий).
- **Серверы** — создание, вступление по коду приглашения, удаление, выход.
- **Каналы** — создание и удаление текстовых каналов, тема канала.
- **Сообщения** — отправка, редактирование, удаление, история с подгрузкой, разбивка по дням,
  группировка подряд идущих сообщений, «печатает…», онлайн-статусы.
- **Личные сообщения** — поиск людей по имени/тегу, диалоги, непрочитанные.
- **Профиль** — имя, описание, цвет аватара.
- **Реальное время** — Socket.IO: сообщения, правки, удаления, новые каналы и участники,
  индикатор набора текста, статусы «в сети».
- **Адаптив** — от широкого монитора до телефона (сайдбар выезжает по кнопке).

## Стек

| Слой | Технологии |
| --- | --- |
| Сервер | Node.js 18+, Express 4, Socket.IO 4 |
| Хранилище | JSON-файл `data/db.json` с атомарной записью (без нативных зависимостей) |
| Клиент | Vanilla JS, HTML, CSS — без сборки и фреймворков |

## Запуск

```bash
npm install        # express + socket.io
npm start          # http://localhost:3000
PORT=8080 npm start
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера |
| `VOLNA_DATA` | `./data` | Каталог, где лежит `db.json` |

## Как пригласить друзей

1. Откройте сервер → «+» рядом с названием (или меню → «Пригласить людей»).
2. Скопируйте код из 8 символов или готовую ссылку `http://host/?invite=xxxx`.
3. Друг нажимает ссылку, вводит код (он подставится сам) — и он на сервере.

## API (кратко)

Все защищённые запросы — с заголовком `Authorization: Bearer <token>`.

| Метод | Путь | Что делает |
| --- | --- | --- |
| POST | `/api/register` | регистрация, возвращает токен |
| POST | `/api/login` | вход |
| GET | `/api/bootstrap` | пользователь, серверы, диалоги, онлайн |
| GET | `/api/servers/:id` | сервер, каналы, участники |
| POST | `/api/servers` | создать сервер |
| POST | `/api/servers/join` | вступить по коду |
| POST | `/api/servers/:id/channels` | создать канал |
| DELETE | `/api/channels/:id` | удалить канал (владелец) |
| GET/POST | `/api/channels/:id/messages` | история / отправка |
| PATCH/DELETE | `/api/messages/:id` | правка / удаление |
| POST | `/api/dm` | открыть личный диалог |
| GET | `/api/users?q=` | поиск людей |

События сокета: `ready`, `presence`, `message:new`, `message:update`, `message:delete`,
`typing`, `typing:stop`, `channel:created`, `channel:deleted`, `member:joined`,
`server:deleted`, `dm:created`.

## Ограничения и планы

Сейчас это крепкий текстовый мессенджер. Дальше напрашивается: загрузка файлов и картинок,
роли и права, реакции на сообщения, голосовые каналы (WebRTC), поиск по истории,
полнотекстовый поиск и переход на SQLite/Postgres для больших инсталляций.

## Безопасность

Пароли хранятся как `scrypt`-хеши с индивидуальной солью, сессии — случайные 256-битные токены.
Доступ к каналам проверяется на каждом запросе, сообщения экранируются на клиенте.
Для публичного размещения поставьте приложение за HTTPS-прокси (Caddy, Nginx) и сделайте бэкап
каталога `data/`.
